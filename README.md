# For Lovey — 21st Birthday Website

A simple mobile-friendly birthday page. Open `index.html` locally to preview it, or publish the folder with GitHub Pages.

## Files to place in this folder

- `index.html` — the website
- `lovey-photo.jpg` — optional opening photo
- `image1.png` through `image6.png` — optional memory photos; missing photos are hidden automatically
- `music.mp3` — your chosen background song

The background music attempts to start after the correct password is submitted and continues looping across the page. If mobile Safari blocks playback or the music file is not present, use the Play button after adding `music.mp3`.
